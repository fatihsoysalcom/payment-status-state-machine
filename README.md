# Payment Status State Machine

This example demonstrates how to manage payment statuses using a simple state machine in Python. It defines valid payment states and allowed transitions between them, ensuring that payment flows are predictable and consistent. The code illustrates successful payments, failed payments with retries, and cancellations.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
